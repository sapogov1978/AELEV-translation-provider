# Сравнение моделей перевода

Неизменяемые результаты завершённого сравнения MADLAD и Index-Translate,
унаследованные при выделении provider. Это аудиторский архив, не активная
инструкция и не часть рабочего исполнения. Исторические команды и пути внутри
результатов относятся к исходному монорепозиторию.

## Основные возможности

- Фиксированный корпус и условия сравнения.
- Сырые переводы, время и память.
- Отдельная безопасная подготовка и очистка эксперимента.

## Запуск и проверки

Историческая регрессия хранится в `test_experiment.py`, но не входит в active
provider suite. Новый quality admission создаёт отдельное evidence для нового
release и не переписывает эти результаты.
