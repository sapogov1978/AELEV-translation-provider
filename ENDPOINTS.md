# HTTP endpoints translator-service

Этот документ описывает операторский и диагностический HTTP API translator-service. Swagger доступен на `/docs`, схема OpenAPI — на `/openapi.json`. Межсервисный перевод остаётся Kafka-only; HTTP-перевод является отдельным операторским действием по [ADR-0109](../../../docs/adr/20261011-0109-operator-translation-through-kafka.md), а не интерфейсом прикладных потребителей.

## Listener и авторизация

Один процесс обслуживает частный диагностический listener и операторский listener. В локальном loopback HTTP-режиме диагностические операции требуют собственного OIDC token и client role `operator-read`. В HTTPS-режиме диагностические операции защищены mTLS на уровне listener; если операторский перевод включён, `POST /v1/translate` дополнительно требует OIDC token с точной аудиторией/`azp` и ролью `operator-translate`.

`AELEV_INFRASTRUCTURE_TRANSLATOR_API_TRANSLATION_ENABLED=false` полностью удаляет `POST /v1/translate` из маршрутов и OpenAPI. Swagger не хранит token после перезагрузки. Обычные ошибки: `401` — чужой или недействительный token, `403` — нет точного права, `413` — тело перевода больше 262144 байт, `422` — неверный вход или терминальный отказ перевода, `429` — занят предел операторских запросов, `502` — повреждённый/несовместимый результат, `503` — identity, storage или Kafka недоступны, `504` — истёк срок ожидания без отмены уже поставленного задания.

## Диагностика

| Метод и путь | Вход | Назначение и ответ |
|---|---|---|
| `GET /healthz` | — | Проверяет только живость API; возвращает `{"status":"ok"}` и не проверяет Kafka, БД или модель. |
| `GET /readyz` | — | Проверяет собственную БД, соединение с Kafka и наличие шести обязательных v1/v2 topics. Возвращает `200` либо `503`; не доказывает продвижение worker или готовность модели. |
| `GET /v1/status` | — | Возвращает желаемое состояние, ревизию управления, priority streak и счётчики заданий по состояниям и очередям без текстов и идентификаторов клиентов. |
| `GET /v1/components` | — | Возвращает свежесть heartbeat обоих consumer, worker, outbox и model. `UNKNOWN` означает отсутствие или просрочку наблюдения; `ONLINE` подтверждает присутствие, но не продвижение очереди. |
| `GET /metrics` | — | Возвращает Prometheus exposition `aelev_translator_jobs{state,queue}` с текущими количествами заданий. |

## Операторский перевод

| Метод и путь | Вход | Назначение и ответ |
|---|---|---|
| `POST /v1/translate` | JSON `source_language`, `target_language`, `queue=normal|priority`, непустой `text` до 12000 символов | При включённой функции создаёт новое операторское намерение, публикует его в выбранную Kafka-очередь и ждёт точного результата после подтверждения outbox. Возвращает `request_id`, языки, очередь, `translated_text` и `warnings`. Тайм-аут или разрыв HTTP не отменяет задание; повторный POST создаёт новое намерение и не является автоматическим retry. |

Коды языков соответствуют закрытому шаблону сервиса, текст обязан быть валидным UTF-8 и не может состоять только из пробелов. Оператор не выбирает модель, выпуск или вычислитель и не вызывает model socket напрямую.
