# Секреты translator-service

Каталог монтируется только для чтения в PostgreSQL и роли translator-service. Файлы, кроме этого README, игнорируются Git и не должны попадать в журналы, команды с подстановкой содержимого или артефакты сборки.

Для локального запуска создайте пароль собственной БД и ограничьте права файла:

```sh
openssl rand -out secrets/postgres-password -hex 32
chmod 600 secrets/postgres-password
```

При `PLAINTEXT` и `sslmode=disable` остальные файлы не требуются, а соответствующие переменные имеют точное значение `NONE`. Для production поместите в этот каталог CA, клиентский сертификат и ключ Kafka и PostgreSQL, задайте в `.env` только их имена без пути и установите права, доступные оператору развёртывания и контейнерному UID `10001` только на чтение. Приватные ключи и пароль не коммитятся.
