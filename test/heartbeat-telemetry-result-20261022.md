## Реализация и установка

На изолированном реальном процессе проверены живой цикл, SIGSTOP с истечением окна, SIGCONT и смерть; 15 опросов, медиана 17,964 мс, максимум 35,784 мс. Это наблюдение стенда, не гарантированный SLO.

Фоновые роли установлены из `sha256:a0dabdbd3f55a1e6aaecb3f18c75b9ffe80d633ea6754f35a0317b06a7b87f3e`, сохранившего все 42 слоя собственного runtime-предшественника. Меняются только три собственных Python-файла и SQLite ABI; веса, Python, ОС и закреплённые зависимости не заменяются. Отдельный `BACKGROUND_IMAGE` не переключил API или модель. ## Собственная защищённая доставка

Sender установлен из закреплённого `aelev/observability-sender:1.0.7@sha256:44e5063c37fd5268d221bf7886a66abb4a256a595190604470bbf1c5e5500739`; фактическая SQLite — 3.53.4. Его ID — `a95eb2f9430f10b6995d88707b76ca6a157bb6bd41110a3c12cb8c27d378782b`, attempts 0 / остаток 3. Проба читает локальный heartbeat; собственный init тома завершается до запуска. Для новой egress-сети явно задана `10.253.40.0/24`: Docker исчерпал автоматический пул; пересечений с 41 существующей сетью и маршрутами Mac не найдено. Чужие сети и настройки daemon не менялись.

Собственные конечные удостоверения подготовлены опубликованным операторским пакетом наблюдения. CA-ключи остались у оператора, runtime получает только свой client-каталог, sender — свой набор. Строгая проверка Python 3.13 обнаружила отсутствующий Authority Key Identifier в начальных листьях; конечные сертификаты дополнены явными SKI/AKI через тот же операторский OpenSSL-интерфейс. Все пять листьев прошли `openssl verify -x509_strict`, все ключи и корни сохранены. Перед краткой остановкой sender сохранены его полные журналы и том; TLS-проверка не ослаблялась. Локальный 30-дневный выпуск не объявляется production-ротацией: допуск внешней площадки остаётся отдельным.

Техническая проба не создавала запрос перевода или предметные данные. Trace `2deedbf518d3d3852a5455c102b68469` найден через документированный Grafana datasource API в Tempo; связанный log найден в Loki по structured metadata `trace_id`.
