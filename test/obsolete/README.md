# Архив результатов translator-service

Исходные JUnit XML сохранены для проверки фактических результатов прежних запусков. Для чтения используйте [отчёт базовых проверок](../pytest-result.md) и [отчёт регрессии provisioning](../provisioner-regression.md). Архив не является инструкцией запуска сервиса или его тестов.

[Отказ поверх существующих данных](lifecycle-preflight-refusal.md) подтверждает остановку до изменений; [первая проверка аварийной очистки](lifecycle-failure-cleanup.md) — удаление созданных ресурсов после намеренной ошибки. Актуальные результаты: [полный жизненный цикл](../lifecycle-result.md) и [аварийная очистка](../lifecycle-failure-cleanup-result.md).
