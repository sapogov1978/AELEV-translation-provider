# Проверка собственного технического состояния

Дата: 2026-10-10. Итог: PASS для публикации состояния и перечисленных локальных проверок.

| Проверка | Результат |
|---|---|
| 45 модульных проверок в собственном контейнере и 10 проверок Compose на операторской машине | PASS |
| Black, Ruff, строгие типы рабочего кода (Pyright) | PASS |
| Самостоятельная сборка собственного образа с включённым wheel и Poetry lock | PASS |
| Реальные stop/start нативных частей: API и строка браузера меняются | PASS |
| Остановка собственного издателя: истечение статуса по реальному TTL и возврат | PASS |
| Восстановление исходных контейнеров в тесте без создания/удаления данных | PASS |

Модульные проверки: `docker run --rm --network none aelev/translator-service:test poetry run pytest -q`; конфигурация: `python3.13 -m pytest -q test/test_configuration.py`. Для воспроизведения нужен Python 3.13 и установленный клиент из собственного `vendor`; версии инструментов закреплены в Poetry lock. Браузерные команды и подготовка удостоверений описаны в [README](../USER_MANUAL.md#диагностика-и-восстановление).

Нативные части проверялись отдельным запуском: [полный отчёт этапов](status-native-result.md), [снимок](status-native.png). Последующий запуск проверял только `--component publisher`: [отчёт](status-publication-result.md), [снимок](status-publication.png). Ни один частичный запуск не выдаётся за проверку всех частей.

Использованы рабочие инфраструктурные компоненты, не тестовые двойники. Временные проверочные контейнеры запускаются с `--rm`. Браузерный тест сам не создаёт identities, контейнеры, сети, тома или предметные задания; останавливаемые контейнеры возвращены, их идентификаторы сверены. Рабочие издатели и их журналы оставлены для эксплуатации и ручной проверки; они созданы при развёртывании и не считаются одноразовыми ресурсами теста. Реально опубликованную последовательность нельзя удалить и начать заново под прежним UUID.

Контейнерный pytest явно пропустил 18 проверок: 10 проверок Docker затем отдельно пройдены на операторской машине; 8 SQL-интеграционных тестов требуют изолированную тестовую БД и в этом прогоне не выполнялись. Собственная миграция `20261010_0003` применена к реальной поставке; наличие и истечение наблюдений подтверждены stop/start. Проверка полной предметной доставки/качества перевода не повторялась; прежние результаты остаются в отдельных отчётах.

Локальная проверка не подтверждает WAN, продукционную PKI/SVID, нагрузку или восстановление резервной копии.  Корневая оркестрация целиком не запускалась: в её текущем env отсутствуют прежние прикладные параметры; сервисные проверки от них не зависят.
