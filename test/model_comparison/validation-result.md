Первоначальный отчёт сохранён как история. Нарушение прежней описи также остаётся в `previous_run` файла [result.json](result.json), хотя текущие вычисления и очистка не изменили исходные Docker-ресурсы. Новая успешная проверка не переписывает прошлую.

Модульные и статические проверки выполнены существующим собственным тестовым образом без сети: `poetry run ruff format --check test/model_comparison`, `poetry run ruff check test/model_comparison`, `poetry run pyright test/model_comparison`, `poetry run pytest -q test/model_comparison/test_experiment.py`. Эти проверки не подменяют реальное исполнение моделей; полный набор регрессий рабочего сервиса и новый вычислитель в production не проверялись, поскольку продуктовая реализация в этом эксперименте не заменялась.
