# Сравнение моделей перевода

Материалы завершённого сравнения MADLAD и Index-Translate; не часть рабочего модельного исполнения.

## Основные возможности

- Фиксированный корпус и условия сравнения.
- Сырые переводы, время и память.
- Отдельная безопасная подготовка и очистка эксперимента.

## Запуск и проверки

Модульная проверка из каталога сервиса: `poetry run pytest -q test/model_comparison/test_experiment.py`. Повтор реального опыта требует отдельной подготовки по [руководству](USER_MANUAL.md), а не запуска старых весов вместо рабочей модели.
