Команды сборки и модульных проверок находятся в [README](../USER_MANUAL.md#диагностика-и-восстановление). Браузерный тест был дополнен проверками порядка заголовков настоящего Swagger и состава схемы; ответы API и собственная OIDC-авторизация не подменялись. Файлы текущего [браузерного отчёта](swagger-local-result.md) и [снимка](swagger-local.png) обновляются последующими проверками; они не являются снимком этого предыдущего прогона. Отдельный прогон операторского перевода сохранён как история.

Оставшиеся восемь пропусков — SQL-тесты, требующие отдельной изолированной базы. Они не запускались и не направлялись на рабочую БД. В Pytest остаются два прежних предупреждения об устаревающих интерфейсах TestClient/AnyIO. Межсервисные Kafka-контракты, данные, параметры модели и версии зависимостей/ОС/Python не менялись. Полный жизненный цикл перевода, удалённое размещение, HTTPS/mTLS и нагрузка в этом прогоне не проверялись. Одноразовые контейнеры проверок удалены через `--rm`; рабочие контейнеры и данные сохранены, адресно обновлён только API своим Compose.

Примечание об очистке 2026-10-12: упомянутые локальные материалы obsolete удалены по отдельному запросу оператора. Исходные результаты, ошибки и ограничения этого отчёта не изменены; удаление архива не является новым успешным прогоном. Перед очисткой сохранена защищённая временная копия вне репозитория.
