# translator-service — проверка локального HTTP/OIDC

Дата: 2026-10-11. Изменения по ADR-0108 применены к собственному API/издателю и универсальной оболочке; версии Python, ОС, модели и существующих библиотек не менялись. Добавлен закреплённый PyJWT с криптографическими зависимостями. Живой адрес Swagger: `http://127.0.0.1:18496/docs`, доступ только с этой станции.

Без токена каждая операция возвращает `401`; собственный действующий JWT разрешает все пять операций. Проверены неверные issuer/audience/authorized party, подпись, сроки, отсутствие права чтения, отказ IdP, запрет неканонических/удалённых HTTP-адресов, широкого host bind и отсутствующих настроек OIDC. HTTPS/mTLS остаётся отдельным явным режимом без автоматического перехода на HTTP; iframe и издательский транспорт сохраняют HTTPS.

## Состояние и ограничения

Из исходной описи 71 контейнера пересозданы только четыре: API/оболочка platform-ui и API/издатель translator-service. Идентификаторы остальных 67 сохранены; новых оставшихся контейнеров нет. Данные, очереди, тома, identities, UUID и журналы последовательностей не удалялись. API и обновлённые компоненты оболочки здоровы; рабочие контейнеры оставлены запущенными для проверки оператором.

Браузер теста не получил клиентского сертификата Swagger. Явное тестовое исключение самоподписанного сертификата касается только существующих loopback IdP/оболочки, не системного доверия или проверки API→IdP. Токены/пароли не записываются в отчёт; блоки запроса с Authorization скрыты на снимке. Режим не обещает доступ через корпоративную политику, запрещающую сам HTTPS IdP.

SQL, повторный полный жизненный цикл перевода, качество перевода, WAN и внешняя production PKI в этом изменении не проверялись. Есть два прежних предупреждения Starlette об устаревших интерфейсах тестового клиента; зависимости ради них не менялись. Полная проверка Black каталога тестов UI обнаруживает прежнее замечание в неизменённом `status_publication.py`; изменённые `api.py` и `test/test_api.py` проходят Black. Исторические отчёты не заменяют этот прогон.
