## Реальный перевод

Проверка `test/swagger_local.py --translate` открыла настоящий Swagger в Chrome, выполнила собственный Authorization Code/PKCE S256 в работающем Keycloak и отправила два задания `en` → `de` с текстом `Hello, world!`. Использованы уже работающие инфраструктурная Kafka, собственная PostgreSQL, consumer, worker, MADLAD и outbox; ответы и модель не подменялись.

| Очередь | Request ID | HTTP | Приоритет в БД | Задание / outbox |
|---|---|---|---|---|
| `normal` | `7b19810f-0ba5-4548-8dee-81137dad72ef` | 200 | 100 | `SUCCEEDED` / `PUBLISHED` |
| `priority` | `0672df92-7661-4f97-8a73-ea30d03a839c` | 200 | 0 | `SUCCEEDED` / `PUBLISHED` |

В обоих ответах модель вернула `Hallo Welt! – 1 Kommentar` и предупреждение `MACHINE_TRANSLATION_UNVERIFIED`. Добавка `– 1 Kommentar` отсутствует в исходном тексте. Это подтверждает технический путь, но не качество перевода; модель, её параметры и веса не менялись. Ответ сохранён без ручной правки или удаления неудобного результата. Подробнее: исторический браузерный отчёт с точным временем, снимок с закрытыми токенами. Архив сохраняет первоначальный прогон до последующего уточнения групп Swagger.

## Очистка и ограничения проверки

Одноразовые Docker-контейнеры проверок и подготовки удалены через `--rm`; созданная SQL-база удалена с проверкой. Браузер закрыт, системное доверие macOS не менялось. Рабочие контейнеры остаются включёнными для проверки оператором. Два принятых учебных задания, сообщения Kafka и результаты сохраняются по штатной политике; рабочие журналы ради очистки не удалялись. Секреты, JWT и OAuth code не записаны в отчёты, команды или снимок; `.env` остаётся игнорируемым.

Этот прогон не проверял удалённый операторский POST по HTTPS/mTLS, WAN, физически разнесённые узлы, нагрузочные пределы и полный stop/start всей поставки. Ошибки/конкурентность проверены регрессиями, не отказами рабочей инфраструктуры. Вход разрешён только оператору: межсервисный перевод остаётся Kafka-only, частный listener не принимает задания, прямого вызова модели из API и новых таблиц/consumer groups/постоянных контейнеров нет. Семантическая добавка модели требует отдельного исследования; PASS этого отчёта не означает её устранение.

Примечание об очистке 2026-10-12: упомянутые локальные материалы obsolete удалены по отдельному запросу оператора. Исходные результаты, ошибки и ограничения этого отчёта не изменены; удаление архива не является новым успешным прогоном. Перед очисткой сохранена защищённая временная копия вне репозитория.
