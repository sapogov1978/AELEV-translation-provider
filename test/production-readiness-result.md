# Проверка готовности translator-service

Дата: 2026-10-14.

Результат продукта: `PASS`.

Изолированный Docker test stage собран только из каталога сервиса. В нём прошли 209 тестов, Ruff и строгий Pyright без ошибок и предупреждений. Двадцать пять сценариев были явно пропущены внутри контейнера: двенадцать требуют host Docker CLI, тринадцать — URL одноразовой PostgreSQL. Compose со всеми профилями отдельно успешно разрешён из `.env.example`; миграция до Alembic head `20261014_0005` и 17 repository-проверок отдельно прошли на одноразовой PostgreSQL 17.6.

Проверки покрывают устойчивые сегментные checkpoints и продолжение длинного задания, ограждение lease, очистку несовместимых сегментов при смене execution, обязательный `sslmode=verify-full` вне local, разделение mounts runtime/deployment identities, обязательность HTTPS/mTLS telemetry endpoint в production и сохранение `traceparent` через consume/process/publish.

Не выполнялись и не объявляются выполненными: фактические SPIFFE/ACL/PKI и независимые failure domains конкретной площадки, внешний backup target, доставка alert в целевой канал, нагрузка нескольких hosts и универсальная смысловая безошибочность модели. Последняя является измеряемым качеством конкретного перевода, а не транспортной гарантией сервиса.
